# 필로소피 채널 대본 말투 (요약)

`philosophy-ai-youtube-script-generator` 스킬이 있으면 그것을 우선한다. 없을 때 이 요약을 따른다.

## 틀
- 시작: `안녕하세요 필로소피입니다 :)` → 오늘 다룰 것을 한두 줄로.
- 끝(outro 장면 그대로):
  ```
  오늘의 영상 여기까지입니다
  영상이 도움이 되셨다면
  좋아요와 구독을 눌러주시면 감사하겠습니다
  감사합니다
  ```
- 분량: 5~10분 영상이면 1,500~3,000자(공백 제외).

## 말투
- 전문적이지만 따뜻한 존댓말, 말하듯 쓴다. 한 줄 = 한 호흡.
- 전환: "네", "그래서", "그러면", "그런데". 감탄: "와", "진짜", "굉장히".
- 화면 안내: "여기서", "이걸 누르시고", "이렇게 나옵니다", "보이시죠?"
- 문어체 → 구어체: "제공합니다" → "해 줘요", "~해야 합니다" → "~해 주세요", "따라서" → "그러니까".
- 겸손: 특정 도구를 최고라고 하지 않는다. "제가 이렇게 쓰고 있다"는 식으로.
- 교육자 대상이면: "지금 보고 계신 선생님들도 …"

## 꼭 넣을 것: "왜"
조작만 나열하지 말고 단계마다 이유를 붙인다.
```
이걸 왜 하냐면
코딩 AI에게 자세하게 요청할수록
우리가 원하는 결과가 나올 확률이 높아지기 때문이에요
```

## 장면 대본 쓰는 요령
- 화면에 보이는 것과 말이 맞게: 확대되는 부분(focus)을 말하는 순간이 장면 중간쯤 오도록 앞에 한두 줄 맥락을 둔다.
- 캡처 속 글을 그대로 읽지 말고 "무엇이 중요한지"를 말한다.
- 이전 영상·외부 사실은 확인된 것만. 모르면 단정하지 않는 문장으로 쓰고 사용자에게 확인을 부탁한다.
- 대본.md에는 장면 번호, `[녹음 파일: id]`, `[화면: …]`, `[자막: points]`가 자동으로 붙는다.
