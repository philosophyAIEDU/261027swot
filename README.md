# 🧭 SWOT 탐험대 — 초등학생용 SWOT 분석 도우미

회사나 가게 이름을 넣으면 Google Gemini AI가 **초등학교 3학년도 읽을 수 있는 말**로 SWOT 분석을 보여 주는 웹 앱이에요.
두 회사를 말하면 자동으로 비교해 주고, 결과를 보고 궁금한 점을 더 물어볼 수도 있어요.

| 칸 | 쉬운 이름 | 뜻 |
| --- | --- | --- |
| S 💪 | 잘하는 점 (Strengths) | 우리가 잘하는 것 |
| W 🩹 | 아쉬운 점 (Weaknesses) | 우리가 아직 부족한 것 |
| O 🌱 | 기회 (Opportunities) | 밖에서 찾아온 좋은 일 |
| T ⚠️ | 조심할 점 (Threats) | 밖에서 찾아올 수 있는 걱정거리 |

- 서버가 없는 정적 웹 앱이에요. 키는 **이 브라우저에만** 저장되고, Gemini API에 질문할 때 말고는 어디에도 보내지 않아요.
- 광고, 회원가입, 외부 분석·추적 스크립트가 없어요.

---

## 1. 내 컴퓨터에서 실행하기

[Node.js 22 LTS](https://nodejs.org/ko)를 먼저 설치하세요. 그다음 이 폴더에서 터미널(명령 프롬프트)을 열고:

```bash
npm install     # 처음 한 번만
npm run dev     # 실행
```

화면에 나오는 주소(보통 `http://localhost:5173`)를 브라우저에서 열면 돼요.

그 밖의 명령:

```bash
npm run build   # 배포용 파일 만들기 (dist 폴더)
npm run test    # 자동 테스트 실행 (실제 AI는 부르지 않아요)
```

> `.env` 파일은 필요 없어요. API 키는 코드나 파일에 넣지 않고, 앱 화면에서 직접 입력해요.

## 2. Gemini API 키 발급하기

1. [Google AI Studio API 키 페이지](https://aistudio.google.com/apikey)에 들어가 Google 계정으로 로그인해요.
2. **API 키 만들기(Create API key)** 버튼을 눌러 새 키를 만들어요.
3. 만든 키를 복사해서 앱 첫 화면 **"어른과 함께 설정해요 🔑"**에 붙여 넣고 **키 확인**을 눌러요.
   앱이 아주 짧은 시험 질문을 보내서 키가 맞는지 확인한 뒤 저장해요.

### ⚠️ 꼭 지켜 주세요

- **키는 다른 사람에게 보여 주지 마세요.** 학생에게 키를 알려 주지 말고, 어른이 직접 입력하세요.
- **공용 컴퓨터에서는 "이 기기에서 기억하기"를 끄세요.**
  - 끔(기본값): 창(탭)을 닫으면 키가 저절로 지워져요.
  - 켬: 이 컴퓨터 브라우저에 키가 계속 남아요. 집 컴퓨터처럼 혼자 쓰는 기기에서만 켜세요.
- **Google AI Studio에서 키 사용량 한도를 설정하세요.** 혹시 키가 새어 나가도 큰 요금이 나오지 않게 막아 줘요.
  (Google Cloud 콘솔의 해당 프로젝트에서 할당량·예산 알림을 설정할 수 있어요.)
- 화면 오른쪽 위 **"🔑 키 바꾸기 / 지우기"**로 언제든 키를 바꾸거나 지울 수 있어요. 수업이 끝나면 지워 두는 것을 권해요.

> 이 앱은 브라우저가 직접 Gemini를 부르는 구조라서, 키는 그 브라우저 안에 있을 수밖에 없어요.
> 그래서 위의 세 가지 안전 수칙이 중요해요. 키는 URL에 절대 넣지 않고 요청 헤더로만 보내요.

## 3. 수업에서 이렇게 써 보세요

- **키는 교사가 입력해요.** 수업 전에 교사용 기기(또는 학생 기기)에서 키를 넣어 두고, 수업이 끝나면 "키 지우기"를 눌러요.
- **처음 배우는 날**: 홈 화면의 "SWOT가 뭐예요?" 카드와 **학교 앞 떡볶이 가게** 예시로 4칸의 뜻과 "안(S, W) / 밖(O, T)" 구분을 함께 읽어요. 이 예시는 AI 없이도 보여요.
- **직접 해 보기**: "내가 직접 채워 보기"에서 학생이 4칸을 먼저 채우면, AI가 칭찬 한 가지와 힌트 한 가지를 줘요(정답을 대신 써 주지 않아요).
- **비교 활동**: "농심이랑 오뚜기 비교해 줘"처럼 쓰거나 "두 회사 비교하기" 버튼으로 두 회사를 넣어요. 비슷한 점 🤝 / 다른 점 ↔️ 표가 나와요. 어느 회사가 "더 좋다"는 판단은 하지 않아요.
- **활동지로 인쇄**: 결과 화면의 **인쇄하기 🖨️**를 누르면 SWOT 4칸이 A4 한 장에 나와요. 접혀 있던 "예를 들면?" 예시도 인쇄에는 모두 들어가요.
  비교 결과는 회사 A, 회사 B, 비교표가 각각 한 장씩 나와요.
- **더 물어보기**: 결과 아래 추천 질문 버튼을 누르거나 직접 질문(300자까지)을 써요.
- **가게 사진으로 알아보기 📷**: 홈 화면의 "사진 넣으러 가기"에서 동네 가게 사진을 한 장 넣으면 AI가 사진 속 단서를 찾아 4칸을 채워요.
  - 각 항목에 **📷 사진에서 봤어요 / 💭 짐작이에요**가 표시돼요. 기회·조심할 점은 사진에 잘 안 보여서 대부분 짐작이에요. "짐작한 내용을 직접 가서 확인해 보기"를 활동으로 이어 가면 좋아요.
  - 가게 이름과 주변 메모(예: 학교 앞, 근처에 공원)를 함께 쓰면 더 정확해져요.
  - 태블릿·휴대폰에서는 "카메라로 찍기" 버튼이 나와요.
  - 사진은 브라우저에서 작게 줄이고, 사진 속 위치(GPS) 정보를 지운 뒤 AI에게만 보내요. 앱에는 사진을 저장하지 않아요(최근 기록에도 결과만 남아요).
  - 학생들에게 "사람 얼굴·차 번호판·전화번호가 나오지 않게, 가게 안은 사장님께 여쭤보고 찍기"를 꼭 안내해 주세요.
  - 이 기능은 사진을 읽을 수 있는 모델이 필요해요. 기본 모델(`gemini-3.5-flash-lite`)로 사진 분석이 안 되면 `src/config.ts`에서 모델을 바꿔 주세요.
- **최신 정보**: "Google 검색으로 최신 정보도 찾아보기"를 켜면 AI가 검색을 참고하고, 참고한 웹 페이지 링크를 보여 줘요.
- 최근 분석한 회사 5개는 이 기기에 저장돼 홈 화면에서 다시 볼 수 있어요(키는 저장하지 않아요).
- 화면 위 **가− / 가+**로 글자 크기를, ☀️/🌙로 어두운 화면을 바꿀 수 있어요.
- AI가 만든 내용은 틀릴 수 있어요. 숫자·날짜 같은 중요한 정보는 학생과 함께 다시 확인해 주세요.

## 4. Netlify로 인터넷에 올리기

1. 이 프로젝트를 GitHub 저장소에 올려요(push).
2. [Netlify](https://app.netlify.com)에 로그인해서 **Add new site → Import an existing project → GitHub**를 고르고 이 저장소를 선택해요.
3. 빌드 설정은 저장소의 `netlify.toml`이 자동으로 적용돼요. 따로 입력할 것이 없어요.
   - 빌드 명령: `npm run build` / 배포 폴더: `dist` / Node 22
   - 외부 스크립트를 막는 보안 헤더(CSP)도 함께 적용돼요.
4. **Deploy**를 누르면 몇 분 뒤 주소가 생겨요.

> 환경 변수(API 키)는 Netlify에 넣지 마세요. 키는 각자 앱 화면에서 입력해요.

## 5. AI 모델 바꾸기

`src/config.ts`의 **한 줄만** 고치면 돼요.

```ts
export const GEMINI_MODEL = 'gemini-3.5-flash-lite';
```

같은 파일의 `THINKING_LEVEL`로 AI가 생각하는 정도를 바꿀 수 있어요(기본 `MINIMAL` = 가장 빠름).
이 모델에는 temperature 같은 값을 넣지 않아요.

## 개발자용 메모

- React 19 + TypeScript(strict) + Vite + Tailwind CSS 4, AI SDK는 `@google/genai`.
- 폴더 구조
  - `src/services/gemini.ts` — 모든 Gemini 호출(`detectIntent`, `analyzeOne`, `analyzeTwo`, `analyzePhoto`, `askFollowUp`, `verifyKey`, `coachPractice`)과 오류 메시지 변환
  - `src/features/photo/` — 사진 고르기 화면과 브라우저 안 사진 손질(1024px로 줄이기, EXIF 제거)
  - `src/services/apiKeyStore.ts` — 키 저장/조회/삭제(sessionStorage 기본, "기억하기"일 때만 localStorage)
  - `src/prompts/` — AI 지시문(공통 규칙, SWOT, 비교, 대화, 판별, 직접 채우기)
  - `src/schemas/` — 응답 JSON 스키마와 런타임 타입 가드
  - `src/features/*` — 화면 기능별 컴포넌트와 커스텀 훅(`useSwotAnalysis`, `useFollowUpChat` 등)
- 분석 흐름: 자유 입력 → 1단계 판별(single / compare / unclear) → 2단계 구조화 출력 → 타입 가드 검사 → 실패 시 1회 재시도.
- AI 답과 사용자 입력은 모두 일반 텍스트로만 보여 줘요(`dangerouslySetInnerHTML`·마크다운 렌더러 없음).
